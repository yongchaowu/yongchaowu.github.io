## About

NewAPI 是新一代的 AI 模型接口管理与分发系统，它基于开源项目 One API 进行了深度二次开发，不仅继承了其优秀的多模型聚合和多租户分发能力，还在模型映射、负载均衡、实时计费和用户体验等方面做了大量增强。

简单来说，NewAPI 可以把市面上几乎所有主流大模型的 API，都转换为统一的 OpenAI 格式（/v1/chat/completions），然后通过你自己的域名和 API Key 对外提供。无论是自己调用，还是分发给团队成员、客户，都能在一个平台上完成密钥生成、额度分配、费率设置和用量监控。
