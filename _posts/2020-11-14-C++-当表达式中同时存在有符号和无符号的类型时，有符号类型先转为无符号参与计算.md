今天看 C++ Primer 时发现：
```cpp
    /* 本例中 int 和 unsigned int 的秩相同，-1 会先转换为 unsigned int */
    unsigned int un1 = 1;
    int n2 = -1;
    std::cout<< "1[unsigned int] * -1[int]" <<un1 * n2<<std::endl; //常见的 32 位 unsigned int 下为 4294967295
```

在 C++ 中，两个整数进行通常算术转换时，并不总是“有符号类型先转为无符号类型”；转换结果还取决于类型的秩、符号以及目标类型能否表示源类型的全部值。

本例中的 `int` 和 `unsigned int` 秩相同，`int` 的负值不能由 `unsigned int` 表示，因此 `n2` 会先转换为 `unsigned int`，乘法按无符号整数运算进行。输出 `4294967295` 假定 `unsigned int` 为常见的 32 位无符号整数；实际位数和结果取决于实现。

参考：[cppreference：Usual arithmetic conversions](https://en.cppreference.com/w/cpp/language/usual_arithmetic_conversions)。
