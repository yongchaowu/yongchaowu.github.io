下面是今天重新看的 《C程序设计语言》书上的例子，这个和之前理解的希尔就没有什么出入了。

```c
void shellSort(int v[], int n){
    int gap, i, j, temp;

    for(gap = n/2; gap > 0; gap /= 2){
        for(i = gap; i < n; i++){
            for(j = i - gap; j>=0 &&v[j]>v[j+gap]; j-=gap){
                temp = v[j];
                v[j] = v[j+gap];
                v[j+gap] = temp;
            }
        }
    }
}

```
