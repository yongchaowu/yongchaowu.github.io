## 编辑部分：

Ctrl + A：全选

<!--more-->

Ctrl + C：复制

Ctrl + X: 剪切

Ctrl + V：粘贴

Ctrl + Z：撤销（后退一步）

Ctrl + S：保存

Ctrl + Y / Ctrl + Shift + Z:重做（也就是前进一步）

**Ctrl+Shift+C：注释掉当前行或选中块
Ctrl+Shift+X：解除注释（最新版的将其替换为截图功能）**

Tab：缩进当前行或选中块

Shift+Tab：减少缩进

按住Ctrl，滚动鼠标滚轮，放大或缩小字体

## 编译与运行部分：
F9：编译并运行当前代码（如果编译错误会提示错误而不会运行）
Ctrl + F9：编译
Ctrl +　Shift + F9:编译当前文件（而不是当前打开的工程项目）

F10:全屏（最新版不能使用）
Ctrl + F10：运行上次成功编译后的程序

Ctrl + C：终止正在运行的程序

Ctrl + Z：终止输入

## 调试部分：
F4：运行到光标所在行

F5：在当前光标所在行设置断点

F7：下一行代码
Shift + F7：进入下一行代码

F8：开始调试
Shift + F8：停止调试

## 界面部分：
Shift + F2：左侧导航栏
