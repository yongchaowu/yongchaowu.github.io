const成员函数
const 成员函数中，`this` 的类型为 `const X*`（`X` 为类类型），因此不能直接修改对象的非 static、非 mutable 成员。

用于声明可通过 const 对象调用的非 static 成员函数。

<!--more-->

单独声明和类外定义时，都要显式写出 `const`。
