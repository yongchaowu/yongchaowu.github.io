阅读说明

这里的内容是从历史文章中重新组织、校订和补充上下文的入口。原始 Markdown 文件、历史 URL 和发布日期均保留；需要逐字查阅时，请从每篇文章底部的“资料来源”进入原文。

How to use this layer

  1. 先从下面的主题入口建立知识框架，再按文章中的顺序阅读历史资料。
  2. 看到版本号、命令或外部链接时，以当前官方文档和实际环境复核；重组稿不替代原始记录。
  3. 如果发现技术错误，优先在来源文章中补充讨论或新建修订稿，不覆盖历史正文。

What happens to the original archive?

历史文章不做批量重写、删除或重命名。它们继续出现在 Archive、主题页和标签页中；本页面只提供一个面向今天读者的入口层。这样既保留旧链接和历史语境，也可以逐步增加经过验证的新版本。
